# PRM Management Skill

This skill manages a Personal Relationship Manager (PRM) stored as a Markdown text blob inside a Notion Code Block.

## Configuration
- **Notion Page ID:** `2e80aff1-c9a9-8092-b8ed-f7b2dd0bed4e`
- **Block ID:** The first Code Block on the page.

## Commands

### `node prm.js list`
Lists all people in the PRM with their IDs and metadata.

### `node prm.js get <name_or_id>`
Get details for a specific person.

### `node prm.js add-note <name_or_id> <note_text> [date]`
Appends a note to a person.
- `date`: Optional, defaults to today (YYYY-MM-DD).
- Automatically updates `last_updated`.

### `node prm.js add-person <full_name> <id> [spouse] [notes]`
Creates a new person block.
- `id`: Must be provided (user-defined or generated by agent).
- `spouse`: Optional.
- `notes`: Initial note.

### `node prm.js update-person <name_or_id> <field> <value>`
Updates metadata (spouse, tags, etc.).
- **Warning:** Use only when explicitly requested.

## Invariants (Strict)
1. **Source of Truth:** The Notion Code Block content.
2. **Immutable IDs:** Never change an ID.
3. **Append-Only Notes:** Never edit/delete old notes.
4. **No Inference:** Do not add unstated facts.
5. **Structure:** Must match:
   ```markdown
   ## Full Name
   id: <id>
   spouse: <value>
   tags: <value>
   last_updated: YYYY-MM-DD

   ### Notes
   - YYYY-MM-DD: Note text
   ```

## Setup
The script requires `NOTION_API_KEY` in the environment.
